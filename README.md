# HashMap in C++

This repository contains my C++ practice and implementations related to **HashMap and Hashing**.

## 📌 About HashMap

A HashMap is a data structure that stores data in the form of **key-value pairs** and provides efficient operations for storing, accessing, and managing data.

Hashing uses a **hash function** to map keys to specific positions in a hash table.
